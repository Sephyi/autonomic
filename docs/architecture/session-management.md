# Session Management Architecture

## 1. Overview and Design Rationale

The `autonomic-session` crate owns the full lifecycle of Claude Code subprocess instances. It is the only component that spawns `claude` processes, parses their output, and reports status back to the orchestrator.

### Design Goals

| Goal | Mechanism |
| --- | --- |
| Structured observability | `--output-format stream-json` gives typed NDJSON on stdout |
| Cost governance | Per-session and global budget tracking from `total_cost_usd` in result messages |
| Parallel safety | Each session runs against an isolated git worktree |
| Crash resilience | Sessions are resumable via `--resume <id>` after unexpected termination |
| Nesting prevention | `CLAUDECODE=1` is stripped from the subprocess environment to allow spawning |
| Least privilege | `--permission-mode acceptEdits` with explicit `--allowedTools` whitelist |

### Non-Goals

- The session manager does not decide *what* to run. Task decomposition and prompt construction live in the orchestrator layer above.
- The session manager does not manage git worktree creation/deletion directly; it accepts a `WorktreeHandle` and validates it before spawn.

## 2. SessionConfig

`SessionConfig` is the complete, validated input required to spawn a session. Every field is explicit; there are no hidden defaults.

```rust
use std::collections::HashMap;
use std::path::PathBuf;
use std::time::Duration;

/// Complete configuration for a single Claude Code session.
///
/// Constructed by the orchestrator, validated at creation time.
/// All paths must be absolute. All optional fields use `Option<T>`.
#[derive(Debug, Clone)]
pub struct SessionConfig {
    /// Unique identifier for this session. Generated by the orchestrator.
    /// Used as the key in all session maps and log correlation.
    pub session_id: SessionId,

    /// Absolute path to the working directory for this session.
    /// Must be an existing directory (typically a git worktree root).
    pub working_dir: PathBuf,

    /// The prompt to send to Claude Code via stdin.
    /// For multi-turn sessions, this is the initial or continuation prompt.
    pub prompt: String,

    /// Model identifier (e.g., "claude-sonnet-4-20250514", "claude-opus-4-20250514").
    /// Passed directly to `--model`.
    pub model: String,

    /// Optional system prompt override. Passed via `--system-prompt`.
    /// When `None`, Claude Code uses its built-in system prompt.
    pub system_prompt: Option<String>,

    /// Tools to auto-approve without interactive confirmation.
    /// Each entry is a tool name string (e.g., "Read", "Write", "Bash").
    /// Passed via `--allowedTools`.
    pub allowed_tools: Vec<String>,

    /// Maximum wall-clock time before the session is killed.
    /// The orchestrator sets this based on task complexity estimates.
    pub timeout: Duration,

    /// Maximum cost in USD this session may accumulate.
    /// When the running total from result messages exceeds this,
    /// the session is terminated gracefully (SIGTERM, then SIGKILL).
    pub cost_budget_usd: f64,

    /// Resume a specific prior session by its Claude Code session ID.
    /// Mutually exclusive with `continue_recent`.
    pub resume_session_id: Option<String>,

    /// Continue the most recent session in the working directory.
    /// Mutually exclusive with `resume_session_id`.
    pub continue_recent: bool,

    /// Additional environment variables to inject into the subprocess.
    /// These are merged on top of the filtered base environment.
    /// Keys that conflict with mandatory env filtering (e.g., `CLAUDECODE`)
    /// are rejected at validation time.
    pub extra_env: HashMap<String, String>,

    /// Enable Claude Code Agent Teams (experimental).
    /// Requires `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1` in env.
    /// Only valid when `model` targets Opus 4.6 1M.
    /// Dramatically increases token usage (~7x).
    pub agent_teams: bool,

    /// Optional handle to the git worktree this session operates in.
    /// The session manager validates the worktree exists before spawning.
    pub worktree: Option<WorktreeHandle>,
}
```

### Validation

`SessionConfig` implements a `validate(&self) -> Result<(), SessionConfigError>` method that is called automatically before spawn. Validation rules:

```rust
impl SessionConfig {
    pub fn validate(&self) -> Result<(), SessionConfigError> {
        // 1. working_dir must be absolute and exist on disk
        if !self.working_dir.is_absolute() {
            return Err(SessionConfigError::RelativePath(self.working_dir.clone()));
        }
        if !self.working_dir.is_dir() {
            return Err(SessionConfigError::WorkingDirNotFound(self.working_dir.clone()));
        }

        // 2. resume_session_id and continue_recent are mutually exclusive
        if self.resume_session_id.is_some() && self.continue_recent {
            return Err(SessionConfigError::ConflictingResumeOptions);
        }

        // 3. agent_teams requires an Opus 4.6 1M model
        if self.agent_teams && !self.model.contains("opus") {
            return Err(SessionConfigError::AgentTeamsRequiresOpus {
                model: self.model.clone(),
            });
        }

        // 4. cost_budget_usd must be positive
        if self.cost_budget_usd <= 0.0 {
            return Err(SessionConfigError::InvalidBudget(self.cost_budget_usd));
        }

        // 5. extra_env must not contain CLAUDECODE
        if self.extra_env.contains_key("CLAUDECODE") {
            return Err(SessionConfigError::ForbiddenEnvVar("CLAUDECODE".into()));
        }

        // 6. If worktree handle is provided, verify it points to a valid directory
        if let Some(ref wt) = self.worktree {
            if !wt.path.is_dir() {
                return Err(SessionConfigError::WorktreeNotFound(wt.path.clone()));
            }
        }

        Ok(())
    }
}
```

## 3. Subprocess Spawning

### Container Isolation

Sessions are spawned INSIDE Podman/Docker containers, not as direct host subprocesses. The orchestrator runs:

```bash
podman run --rm \
  -v project:/workspace:rw \
  -v claude-config:/home/agent/.claude:ro \
  --memory 4g --cpus 2 \
  -e ANTHROPIC_API_KEY \
  autonomic-agent:latest \
  claude -p "..." --output-format stream-json
```

This provides filesystem isolation, resource limits, and reproducible environments for each session. The host daemon communicates with the container via stdout/stderr streams, identical to the direct subprocess model.

### Container Lifecycle

```txt
1. CREATE   — podman create with image, resource limits, env vars
2. CONFIGURE — bind mounts (project dir, claude config), env injection, network policy
3. RUN      — podman start, capture stdout/stderr streams
4. CAPTURE  — parse stream-json output, track cost, enforce timeout
5. DESTROY  — podman rm (--rm flag auto-removes on exit)
```

### Command Construction

The session manager builds the `tokio::process::Command` deterministically from a validated `SessionConfig`. The command targets `podman run` (or `docker run`) wrapping the `claude` CLI inside the container. No flags are inferred or defaulted at spawn time.

```rust
use tokio::process::Command;
use std::process::Stdio;

/// Builds the Command from a validated SessionConfig.
/// This is a pure function with no side effects.
fn build_command(config: &SessionConfig) -> Command {
    let mut cmd = Command::new("claude");

    // Core flags: print mode with streaming JSON output
    cmd.arg("--print");
    cmd.arg("--output-format").arg("stream-json");

    // Permission mode: acceptEdits (never dangerously-skip-permissions)
    cmd.arg("--permission-mode").arg("acceptEdits");

    // Model selection
    cmd.arg("--model").arg(&config.model);

    // System prompt (optional)
    if let Some(ref sp) = config.system_prompt {
        cmd.arg("--system-prompt").arg(sp);
    }

    // Allowed tools whitelist
    if !config.allowed_tools.is_empty() {
        let tools_csv = config.allowed_tools.join(",");
        cmd.arg("--allowedTools").arg(&tools_csv);
    }

    // Session resume/continue
    if let Some(ref resume_id) = config.resume_session_id {
        cmd.arg("--resume").arg(resume_id);
    } else if config.continue_recent {
        cmd.arg("--continue");
    }

    // The prompt is the final positional argument
    cmd.arg("--");
    cmd.arg(&config.prompt);

    // Working directory
    cmd.current_dir(&config.working_dir);

    // I/O handles
    cmd.stdout(Stdio::piped());
    cmd.stderr(Stdio::piped());
    cmd.stdin(Stdio::null());

    // Environment: start from filtered parent env, merge extras
    cmd.env_clear();
    for (key, value) in std::env::vars() {
        // CLAUDECODE=1 blocks subprocess spawning of claude instances.
        // It is set by Claude Code in its own children to prevent nesting.
        // We MUST strip it so our managed subprocesses can run.
        if key == "CLAUDECODE" {
            continue;
        }
        cmd.env(&key, &value);
    }

    // Inject user-specified extra env vars (already validated)
    for (key, value) in &config.extra_env {
        cmd.env(key, value);
    }

    // Agent Teams: experimental flag via env var
    if config.agent_teams {
        cmd.env("CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS", "1");
    }

    cmd
}
```

### Critical: `CLAUDECODE` Filtering

When Claude Code runs, it sets `CLAUDECODE=1` in its own process environment. Any child process that inherits this variable is blocked from invoking Claude Code (the CLI detects the variable and refuses to start, as a nesting guard). Because Autonomic is itself running *under* Claude Code in some deployment scenarios, the subprocess environment **must** be filtered.

The filtering is implemented as a deny-list during `env_clear()` + selective re-add, not as a post-hoc `env_remove()`, to ensure no code path can accidentally skip it.

## 4. Output Parsing

### Stream-JSON Format

Claude Code `--output-format stream-json` emits newline-delimited JSON (NDJSON) on stdout. Each line is a self-contained JSON object with a `type` field.

### Message Types

The session manager must handle the following message types:

| `type` | `subtype` | Meaning | Action |
| --- | --- | --- | --- |
| `assistant` | `text` | Text content from Claude | Forward to event stream, accumulate for transcript |
| `assistant` | `tool_use` | Claude is invoking a tool | Log tool name and input |
| `tool` | `tool_result` | Result of tool execution | Log result summary |
| `system` | (various) | System-level messages | Log, check for rate limit signals |
| `result` | `success` | Session completed successfully | Transition to `Completed`, extract `total_cost_usd` |
| `result` | `error` | Session ended with an error | Transition to `Failed`, extract error details |
| `result` | `max_turns` | Session hit the turn limit | Transition to `Completed` with truncation flag |

### Parsing Implementation

```rust
use serde::Deserialize;
use tokio::io::{AsyncBufReadExt, BufReader};

/// A single message from the Claude Code stream-json output.
/// Only fields the session manager needs are deserialized;
/// all other fields are captured in `extra` for passthrough.
#[derive(Debug, Deserialize)]
pub struct StreamMessage {
    /// Top-level message type: "assistant", "tool", "system", "result"
    #[serde(rename = "type")]
    pub message_type: String,

    /// Sub-type within the message type (e.g., "text", "success", "error")
    #[serde(default)]
    pub subtype: Option<String>,

    /// Cost in USD accumulated so far (present on "result" messages)
    #[serde(default)]
    pub total_cost_usd: Option<f64>,

    /// Duration in milliseconds (present on "result" messages)
    #[serde(default)]
    pub duration_ms: Option<u64>,

    /// Session ID assigned by Claude Code (present on "result" messages)
    #[serde(default)]
    pub session_id: Option<String>,

    /// Human-readable result text (present on "result" messages)
    #[serde(default)]
    pub result: Option<String>,

    /// Error message (present when subtype == "error")
    #[serde(default)]
    pub error: Option<String>,

    /// Remaining fields captured for passthrough / logging
    #[serde(flatten)]
    pub extra: serde_json::Value,
}

/// Reads stdout line by line, deserializes each JSON message,
/// and sends parsed messages through the provided channel.
async fn parse_output_stream(
    stdout: tokio::process::ChildStdout,
    tx: tokio::sync::mpsc::UnboundedSender<StreamMessage>,
) -> Result<(), SessionError> {
    let reader = BufReader::new(stdout);
    let mut lines = reader.lines();

    while let Some(line) = lines.next_line().await? {
        let line = line.trim().to_string();
        if line.is_empty() {
            continue;
        }

        match serde_json::from_str::<StreamMessage>(&line) {
            Ok(msg) => {
                if tx.send(msg).is_err() {
                    // Receiver dropped; session is being torn down
                    break;
                }
            }
            Err(e) => {
                // Non-JSON lines may appear (e.g., claude CLI warnings).
                // Log and continue; do not abort the session.
                tracing::warn!(
                    line = %line,
                    error = %e,
                    "Failed to parse stream-json line; skipping"
                );
            }
        }
    }

    Ok(())
}
```

### Completion Detection

A session is considered complete when a message arrives with `message_type == "result"`. The `subtype` determines the outcome:

```rust
fn classify_result(msg: &StreamMessage) -> SessionOutcome {
    match msg.subtype.as_deref() {
        Some("success") => SessionOutcome::Success {
            result_text: msg.result.clone(),
            cost_usd: msg.total_cost_usd.unwrap_or(0.0),
            duration_ms: msg.duration_ms.unwrap_or(0),
            claude_session_id: msg.session_id.clone(),
        },
        Some("error") => SessionOutcome::Error {
            error: msg.error.clone().unwrap_or_else(|| "unknown error".into()),
            cost_usd: msg.total_cost_usd.unwrap_or(0.0),
        },
        Some("max_turns") => SessionOutcome::MaxTurns {
            result_text: msg.result.clone(),
            cost_usd: msg.total_cost_usd.unwrap_or(0.0),
            claude_session_id: msg.session_id.clone(),
        },
        other => SessionOutcome::Error {
            error: format!("Unknown result subtype: {:?}", other),
            cost_usd: msg.total_cost_usd.unwrap_or(0.0),
        },
    }
}
```

### State Machine

```txt

  Created ──────────────> Ready ──────────> Running

                          ┌───────────────────┼───────────────────┐
                          │                   │                   │
```

### State Definitions

```rust
use std::time::Instant;

/// Unique session identifier. Wraps a UUID v7 for time-ordering.
#[derive(Debug, Clone, PartialEq, Eq, Hash)]
pub struct SessionId(pub uuid::Uuid);

impl SessionId {
    pub fn new() -> Self {
        Self(uuid::Uuid::now_v7())
    }
}

/// The observable state of a session.
#[derive(Debug, Clone)]
pub enum SessionState {
    /// Config created, not yet validated.
    Created,

    /// Validated and ready to spawn.
    Ready,

    /// Subprocess is running. Contains live tracking data.
    Running {
        pid: u32,
        started_at: Instant,
        accumulated_cost_usd: f64,
        last_message_at: Instant,
        claude_session_id: Option<String>,
    },

    /// Session completed with a definitive outcome.
    Completed {
        outcome: SessionOutcome,
        started_at: Instant,
        finished_at: Instant,
    },

    /// Session failed (process crash, parse error, budget exceeded).
    Failed {
        error: SessionError,
        started_at: Option<Instant>,
        finished_at: Instant,
    },

    /// Session was killed due to timeout.
    TimedOut {
        started_at: Instant,
        finished_at: Instant,
        accumulated_cost_usd: f64,
    },

    /// Terminal state. Session data has been persisted and can be reclaimed.
    Archived,
}

/// The outcome of a successfully terminated session.
#[derive(Debug, Clone)]
pub enum SessionOutcome {
    Success {
        result_text: Option<String>,
        cost_usd: f64,
        duration_ms: u64,
        claude_session_id: Option<String>,
    },
    Error {
        error: String,
        cost_usd: f64,
    },
    MaxTurns {
        result_text: Option<String>,
        cost_usd: f64,
        claude_session_id: Option<String>,
    },
}
```

### Lifecycle Orchestration

```rust
impl SessionManager {
    /// Runs a session to completion. This is the primary entry point.
    ///
    /// Returns the final SessionState (always Completed, Failed, or TimedOut).
    /// The caller is responsible for transitioning to Archived after
    /// processing the result.
    pub async fn run_session(
        &self,
        config: SessionConfig,
    ) -> Result<SessionRecord, SessionError> {
        // 1. Validate
        config.validate()?;

        // 2. Build command
        let mut cmd = build_command(&config);

        // 3. Spawn
        let mut child = cmd.spawn().map_err(SessionError::SpawnFailed)?;
        let pid = child.id().unwrap_or(0);
        let started_at = Instant::now();

        // 4. Take stdout handle for parsing
        let stdout = child.stdout.take()
            .ok_or(SessionError::NoStdout)?;

        // 5. Set up message channel
        let (tx, mut rx) = tokio::sync::mpsc::unbounded_channel::<StreamMessage>();

        // 6. Spawn output parser task
        let parser_handle = tokio::spawn(parse_output_stream(stdout, tx));

        // 7. Process messages with timeout and budget enforcement
        let outcome = self.monitor_session(
            &config,
            &mut child,
            &mut rx,
            started_at,
        ).await;

        // 8. Ensure child is reaped
        let _ = child.wait().await;

        // 9. Ensure parser task completes
        let _ = parser_handle.await;

        // 10. Build final record
        let finished_at = Instant::now();
        Ok(SessionRecord {
            session_id: config.session_id.clone(),
            config,
            state: outcome,
            started_at,
            finished_at,
        })
    }
}
```

## 6. Cost Tracking and Rate Budget Integration

### Per-Session Cost Tracking

Cost is extracted from `total_cost_usd` on `result` messages. During a running session, intermediate cost is not available from Claude Code's stream output (only the final result includes it). However, for long sessions, the session manager enforces a wall-clock timeout as a proxy for cost control.

```rust
/// Global cost tracker shared across all sessions.
/// Thread-safe via interior mutability (DashMap).
pub struct CostTracker {
    /// Per-session costs, keyed by SessionId.
    session_costs: DashMap<SessionId, f64>,

    /// Rolling window of costs for rate limit awareness.
    /// Entries are (timestamp, cost_usd).
    cost_history: Mutex<Vec<(Instant, f64)>>,

    /// Global budget ceiling in USD. When the rolling window sum
    /// exceeds this, new sessions are blocked until costs age out.
    global_budget_usd: f64,

    /// Window duration for the rolling budget.
    budget_window: Duration,
}

impl CostTracker {
    /// Record a session's final cost. Called when a session transitions
    /// to Completed or Failed.
    pub fn record_cost(&self, session_id: &SessionId, cost_usd: f64) {
        self.session_costs.insert(session_id.clone(), cost_usd);
        let mut history = self.cost_history.lock().unwrap();
        history.push((Instant::now(), cost_usd));
    }

    /// Check whether a new session with the given estimated cost
    /// can be started within the global budget window.
    pub fn can_afford(&self, estimated_cost_usd: f64) -> bool {
        let mut history = self.cost_history.lock().unwrap();
        let cutoff = Instant::now() - self.budget_window;
        history.retain(|(t, _)| *t > cutoff);
        let window_total: f64 = history.iter().map(|(_, c)| c).sum();
        window_total + estimated_cost_usd <= self.global_budget_usd
    }

    /// Total cost accumulated across all sessions (lifetime).
    pub fn total_cost(&self) -> f64 {
        self.session_costs.iter().map(|entry| *entry.value()).sum()
    }
}
```

### Rate Limit Awareness

Claude Max rate limits are per-account and shared across all concurrent sessions. The session manager does not attempt to model the exact rate limit (which depends on model, plan tier, and server-side state). Instead, it uses these heuristics:

1. **Concurrency cap**: A configurable maximum number of concurrent `Running` sessions (default: 5). This prevents stampeding the rate limit.
2. **Backoff on 429**: If stderr output contains rate-limit indicators (HTTP 429 or "rate limit" text), the session is paused and retried with exponential backoff.
3. **Global budget window**: The `CostTracker` provides a sliding-window budget to prevent runaway spending.

```rust
/// Configuration for rate limit management.
pub struct RateLimitConfig {
    /// Maximum concurrent running sessions.
    pub max_concurrent_sessions: usize,

    /// Initial backoff duration after a rate limit hit.
    pub initial_backoff: Duration,

    /// Maximum backoff duration.
    pub max_backoff: Duration,

    /// Backoff multiplier per consecutive rate limit hit.
    pub backoff_multiplier: f64,
}

impl Default for RateLimitConfig {
    fn default() -> Self {
        Self {
            max_concurrent_sessions: 5,
            initial_backoff: Duration::from_secs(10),
            max_backoff: Duration::from_secs(300),
            backoff_multiplier: 2.0,
        }
    }
}
```

## 7. Worktree Isolation

Each parallel session operates in its own git worktree to prevent file conflicts. Worktree creation and cleanup are handled by a separate `WorktreeManager`; the session manager only receives a validated handle.

```rust
/// Opaque handle to an existing git worktree.
/// The session manager does not create or destroy worktrees.
#[derive(Debug, Clone)]
pub struct WorktreeHandle {
    /// Absolute path to the worktree root directory.
    pub path: PathBuf,

    /// Branch name checked out in this worktree.
    pub branch: String,

    /// The base repository path (for reference only).
    pub repo_root: PathBuf,
}
```

### Worktree Contract

The session manager enforces the following contract at spawn time:

1. `worktree.path` must exist and be a directory.
2. `worktree.path` must contain a `.git` file (worktrees use a `.git` file, not a directory).
3. `config.working_dir` must equal `worktree.path` when a worktree handle is provided.

```rust
fn validate_worktree(config: &SessionConfig) -> Result<(), SessionConfigError> {
    if let Some(ref wt) = config.worktree {
        // Worktree directory must exist
        if !wt.path.is_dir() {
            return Err(SessionConfigError::WorktreeNotFound(wt.path.clone()));
        }

        // Worktree must have a .git file (not directory)
        let git_path = wt.path.join(".git");
        if !git_path.is_file() {
            return Err(SessionConfigError::InvalidWorktree(wt.path.clone()));
        }

        // working_dir must match worktree path
        if config.working_dir != wt.path {
            return Err(SessionConfigError::WorkingDirWorktreeMismatch {
                working_dir: config.working_dir.clone(),
                worktree_path: wt.path.clone(),
            });
        }
    }
    Ok(())
}
```

## 8. Session Resume/Continue Patterns

Claude Code supports two mechanisms for continuing prior work:

### `--continue` (Continue Most Recent)

Continues the most recent conversation in the current working directory. Use when a session timed out or was interrupted and the orchestrator wants to pick up where it left off.

```rust
/// Create a config that continues the most recent session
/// in the given working directory.
fn continue_session(
    original: &SessionConfig,
    continuation_prompt: &str,
) -> SessionConfig {
    SessionConfig {
        session_id: SessionId::new(),
        prompt: continuation_prompt.to_string(),
        continue_recent: true,
        resume_session_id: None,
        // Carry forward all other settings from the original config
        working_dir: original.working_dir.clone(),
        model: original.model.clone(),
        system_prompt: original.system_prompt.clone(),
        allowed_tools: original.allowed_tools.clone(),
        timeout: original.timeout,
        cost_budget_usd: original.cost_budget_usd,
        extra_env: original.extra_env.clone(),
        agent_teams: original.agent_teams,
        worktree: original.worktree.clone(),
    }
}
```

**CRITICAL: Orphan Process Prevention** (Gemini review finding): If the daemon crashes or is killed (SIGKILL), child Claude Code processes are detached and continue running — burning rate budget silently. Mitigations:
1. Each session writes its child PID to `~/.autonomic/state/sessions/<session_id>.pid`.
2. The watchdog sweeps for orphaned `claude` processes on every startup (match PID files against running processes).
3. The daemon writes a heartbeat to `~/.autonomic/state/daemon-heartbeat` every 30s. Sessions can self-terminate if heartbeat is stale (>90s).
4. On graceful shutdown (SIGTERM), the daemon sends SIGTERM to all children and waits up to 30s before SIGKILL.

**CRITICAL: System prompt does NOT persist across --resume** (discovered from ClaudeClaw source code analysis). The `--append-system-prompt` flag does not persist across session resumes. The orchestrator MUST re-inject the full system context (identity, project context, memory assembly) on every `--resume` call. This is not optional — without re-injection, resumed sessions lose all orchestrator context.

### `--resume <session_id>` (Resume Specific Session)

Resumes a specific Claude Code session by its internal session ID (available from `session_id` in result messages). Use when the orchestrator needs to resume a known session, regardless of what happened since.

```rust
/// Create a config that resumes a specific Claude Code session.
fn resume_session(
    original: &SessionConfig,
    claude_session_id: &str,
    continuation_prompt: &str,
) -> SessionConfig {
    SessionConfig {
        session_id: SessionId::new(),
        prompt: continuation_prompt.to_string(),
        resume_session_id: Some(claude_session_id.to_string()),
        continue_recent: false,
        working_dir: original.working_dir.clone(),
        model: original.model.clone(),
        system_prompt: original.system_prompt.clone(),
```

### Resume Strategy Decision

```rust
/// Determines the appropriate resume strategy after a session ends
/// without achieving the desired outcome.
fn decide_resume_strategy(
    record: &SessionRecord,
    retry_count: u32,
    max_retries: u32,
) -> ResumeStrategy {
    if retry_count >= max_retries {
        return ResumeStrategy::Abort;
    }

    match &record.state {
        SessionState::TimedOut { .. } => {
            // Timed out: continue where it left off
            if let Some(ref claude_id) = extract_claude_session_id(record) {
                ResumeStrategy::Resume {
                    claude_session_id: claude_id.clone(),
                    prompt: "Continue from where you left off. \
                             Focus on completing the remaining work.".into(),
                }
            } else {
                ResumeStrategy::Continue {
                    prompt: "The previous attempt timed out. \
                             Continue the work.".into(),
                }
            }
        }
        SessionState::Failed { error, .. } => {
            match error {
                SessionError::RateLimited => ResumeStrategy::BackoffAndRetry,
                SessionError::ProcessCrashed { .. } => {
                    // Crash: resume the specific session to recover context
                    if let Some(ref claude_id) = extract_claude_session_id(record) {
                        ResumeStrategy::Resume {
                            claude_session_id: claude_id.clone(),
                            prompt: "The session was interrupted. \
                                     Please continue.".into(),
                        }
                    } else {
                        ResumeStrategy::Restart
                    }
                }
                _ => ResumeStrategy::Abort,
            }
        }
        _ => ResumeStrategy::Abort,
    }
}

#[derive(Debug)]
pub enum ResumeStrategy {
    /// Resume a specific session by Claude Code session ID.
    Resume { claude_session_id: String, prompt: String },
    /// Continue the most recent session in the working directory.
    Continue { prompt: String },
    /// Wait for backoff, then retry from scratch.
    BackoffAndRetry,
    /// Start a completely new session.
    Restart,
    /// Give up.
    Abort,
}
```

## 9. Agent Teams Integration

Claude Code Agent Teams is an experimental feature where the primary Claude instance can spawn sub-agents for parallel work. It is significantly more expensive (~7x token cost) but can dramatically reduce wall-clock time for complex, multi-file tasks.

**CooperBench Warning**: Research shows agents achieve ~50% lower success when collaborating vs solo (LLM-based MAS Design Patterns study, 94 papers analyzed). Agent Teams should be used ONLY for truly parallelizable work (e.g., 3 independent file modifications in worktree isolation). Never for collaborative reasoning, shared decision-making, or tasks where agents need to coordinate on shared state. All inter-agent coordination must flow through the orchestrator, not peer-to-peer.

### Constraints

- Requires `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1` environment variable
- Only supported with Opus 4.6 1M model
- Multiplies token usage by approximately 7x
- The sub-agents share the same rate limit pool as the parent

### Cost Gate

Agent Teams must pass a cost gate before being enabled:

```rust
/// Decides whether to enable Agent Teams for a given task.
pub struct AgentTeamsGate {
    /// Minimum estimated task complexity (in arbitrary units)
    /// below which Agent Teams is never enabled.
    pub min_complexity_threshold: u32,

    /// Maximum cost multiplier the budget can absorb.
    /// Agent Teams uses ~7x tokens, so this should be >= 7.0.
    pub max_cost_multiplier: f64,

    /// The per-session budget must be at least this value (USD)
    /// for Agent Teams to be considered.
    pub min_session_budget_usd: f64,
}

impl AgentTeamsGate {
    pub fn should_enable(
        &self,
        task_complexity: u32,
        session_budget_usd: f64,
        cost_tracker: &CostTracker,
    ) -> bool {
        // 1. Task must be complex enough to benefit
        if task_complexity < self.min_complexity_threshold {
            return false;
        }

        // 2. Session budget must accommodate the multiplier
        if session_budget_usd < self.min_session_budget_usd {
            return false;
        }

        // 3. Global budget must have headroom for 7x cost
        let estimated_cost = session_budget_usd; // worst case: use full budget
        cost_tracker.can_afford(estimated_cost)
    }
}

impl Default for AgentTeamsGate {
    fn default() -> Self {
        Self {
            min_complexity_threshold: 8,
            max_cost_multiplier: 7.0,
            min_session_budget_usd: 2.0,
        }
    }
}
```

### Timeout Enforcement

```rust
/// Monitors a running session, enforcing timeout and budget limits.
/// Returns the final session state.
async fn monitor_session(
    &self,
    config: &SessionConfig,
    child: &mut tokio::process::Child,
    rx: &mut tokio::sync::mpsc::UnboundedReceiver<StreamMessage>,
    started_at: Instant,
) -> SessionState {
    let deadline = tokio::time::sleep(config.timeout);
    tokio::pin!(deadline);

    let mut accumulated_cost = 0.0_f64;
    let mut last_message_at = Instant::now();
    let mut claude_session_id: Option<String> = None;
    let mut final_outcome: Option<SessionOutcome> = None;

    loop {
        tokio::select! {
            // Timeout fires
            _ = &mut deadline => {
                // Graceful shutdown: SIGTERM, wait 5s, then SIGKILL
                Self::terminate_child(child).await;
                return SessionState::TimedOut {
                    started_at,
                    finished_at: Instant::now(),
                    accumulated_cost_usd: accumulated_cost,
                };
            }

            // New message from the output parser
            msg = rx.recv() => {
                match msg {
                    Some(message) => {
                        last_message_at = Instant::now();

                        // Extract session ID if present
                        if let Some(ref sid) = message.session_id {
                            claude_session_id = Some(sid.clone());
                        }

                        // Check for result message (completion)
                        if message.message_type == "result" {
                            if let Some(cost) = message.total_cost_usd {
                                accumulated_cost = cost;
                            }
                            final_outcome = Some(classify_result(&message));
                            break;
                        }

                        // Forward message to event subscribers
                        self.event_tx.send(SessionEvent::Message {
                            session_id: config.session_id.clone(),
                            message,
                        }).ok();
                    }
                    None => {
                        // Parser channel closed without a result message.
                        // The process likely crashed.
                        break;
                    }
                }
            }
        }
    }

    // Determine final state
    match final_outcome {
        Some(outcome) => SessionState::Completed {
            outcome,
            started_at,
            finished_at: Instant::now(),
        },
        None => {
            // No result message received; process crashed or was killed
            let status = child.wait().await.ok();
            let exit_code = status.and_then(|s| s.code());
            #[cfg(unix)]
            let signal = status.and_then(|s| {
                use std::os::unix::process::ExitStatusExt;
                s.signal()
            });
            #[cfg(not(unix))]
            let signal = None;

            SessionState::Failed {
                error: SessionError::ProcessCrashed {
                    exit_code,
                    signal,
                    stderr: String::new(), // stderr captured separately
                },
                started_at: Some(started_at),
                finished_at: Instant::now(),
            }
        }
    }
}
```

### Graceful Termination

```rust
/// Terminates a child process gracefully.
/// Sends SIGTERM, waits up to 5 seconds, then sends SIGKILL.
async fn terminate_child(child: &mut tokio::process::Child) {
    #[cfg(unix)]
    {
        use nix::sys::signal::{kill, Signal};
        use nix::unistd::Pid;

        if let Some(pid) = child.id() {
            let _ = kill(Pid::from_raw(pid as i32), Signal::SIGTERM);
        }
    }

    // Wait up to 5 seconds for graceful exit
    let graceful = tokio::time::timeout(
        Duration::from_secs(5),
        child.wait(),
    ).await;

    if graceful.is_err() {
        // Process did not exit; force kill
        let _ = child.kill().await;
        let _ = child.wait().await;
    }
}
```
